        Reader — a self-contained local document reader. Markdown and code open with editing and saving; CSV renders as tables; PDF uses your browser's own viewer. It runs from a single folder on your Mac, uses only the Python standard library, and never reaches the network.

        The server listens on 127.0.0.1 only, at a fixed port (8737, or the next free one if that is taken), and every request carries a secret token kept beside the app, so the address stays bookmarkable and nothing else on your machine or network can read your files through it. Rendered HTML is sanitised, and saves are atomic.

        Bundled offline: marked (markdown), DOMPurify (sanitising), highlight.js (code), and the Poppins, Lora, Inter, Source Serif 4 and JetBrains Mono typefaces. Licences are in the licenses folder next to the app.
